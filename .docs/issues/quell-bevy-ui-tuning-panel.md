# feat: bevy_ui tuning panel for runtime settings

Repo: `cubething-qproj/quell` · Labels: `enhancement` · Filed: #26 (updated after #31)

## Problem

Runtime tuning goes through `bevy-inspector-egui`. #31 fixed its input conflict (egui now absorbs the clicks and typing it uses), so that is no longer the motivation. The goal is a Bevy-native (`bevy_ui`) tuning surface for the settings being tuned, as a first step towards eventually replacing the egui world inspector with a `bevy_ui` one.

## Direction

- A `dev`-only `bevy_ui` panel for adjusting the tweakable `Resource` settings (e.g. `PlayerSettings`, camera settings), with rows generated by reflection for resources registered as tunable.
- Use Bevy's Feathers widgets (sliders, number inputs).
- Gameplay input is suppressed while the panel is hovered or focused, starting with cursor capture.
- The panel relies on `bevy_picking`'s mouse pointer, which needs `q_screens` 0.2.0 (quell#32) so the pointer survives screen changes.
- Replacing egui wholesale is out of scope for this issue; it's the longer-term direction.

## Acceptance

- Clicking the panel never captures the cursor.
- Edits apply live to existing entities.
