Keep the library independent of `q_screens`, Quell input actions, `ScreenScoped`, `AppSettings`, and Quell's `CollisionLayer`. Remove superseded camera implementations, unused settings fields (such as the currently unused `rotation_speed`), adapters, imports, and obsolete tests in Quell once their replacements are verified; do not leave parallel/stale code or change live numeric tuning.

- Keep **19 application cases in Quell**: the other three free tests (bundle/input isolation, Escape-vs-quit, screen change); four orbit/zoom/input-gate tests; the mixed-layer/player/body/sensor/camera filtering test against Quell's actual `CollisionLayer` configuration; all seven switching/HUD/capture tests; and all four player tests. - Count test cases and compare names/behaviors before and after the move; no test silently disappears. Selected-schedule unit tests do not replace full-app fixed-step or Quell lifecycle tests. Add only tests needed to cover a new configuration seam.
